WHERE PHANTOMX FITS

PhantomX occupies the unified assessment layer — the space between single-purpose specialist tools. Where Metasploit requires expert knowledge of individual exploits, Nmap requires post-processing, BloodHound requires a Windows agent, and Burp Suite requires manual proxy configuration, PhantomX provides a single Python CLI with zero external dependencies that covers reconnaissance through post-exploitation in one coherent pipeline.

It is not a replacement for specialist tools on deep engagements — it is the first-pass triage layer that identifies what specialist tools to deploy next, generates risk-scored reports automatically, and runs on any Kali Linux host with Python 3.8+.
