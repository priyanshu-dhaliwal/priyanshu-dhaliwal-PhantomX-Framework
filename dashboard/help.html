🚩Global Flags
💡 Global flags must come BEFORE the module name: python3 main.py --verbose privesc ✓  |  python3 main.py privesc --verbose ✗
FlagValuesDescription
--verbose / -vflagEnable detailed output — show more findings and raw data
--output / -ohtml, json, txtAuto-save report after module completes
--interactive / -iflagForce full 5-step wizard even if module is specified
--no-colorflagDisable ANSI colours (useful for log files and pipes)
--versionflagPrint PhantomX version and exit
--help / -hflagShow usage for any command or module
--targetIP / hostnameTarget for network modules — prompted if omitted
--domaincorp.localDomain name for AD / DNS modules — prompted if omitted
--portintegerWeb port for webapp/vulnscan/fuzzer (default: 80)
