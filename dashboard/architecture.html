Data Flow

1. Execution
  • User invokes CLI or TUI
  • Argparse parses module name
  • Engine looks up MODULE_MAP
  • Plugin file imported dynamically
2. Discovery
  • Plugin calls shell utils
  • Subprocess runs system tools
  • Results parsed via regex
  • Dict returned to engine
3. Analysis
  • Engine stores results in session
  • Scoring engine applies 40+ rules
  • CVSS-like scores assigned
  • Remediation actions mapped
4. Reporting
  • Session JSON persisted to disk
  • Report generator invoked
  • HTML/JSON/TXT written
  • Dashboard loads JSON for viz
5. Alerting
  • autorun.sh parses session JSON
  • Critical findings extracted
  • Slack/Discord/Email alerts fired
  • Log file written for audit trail
